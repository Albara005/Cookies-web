# كوكيز البيت: موقع كوكيز منزلية

صفحة هبوط بالعربية (من اليمين إلى اليسار) لمخبز كوكيز منزلي، بأربعة أقسام وكوكيز ثلاثية الأبعاد تتنقّل بينها:

1. **النكهات:** قوس دوّار من 8 كوكيز ثلاثية الأبعاد. اسحب أو اضغط على كوكيز أو زر السهم، فتتغيّر الخلفية بدائرة لون تكبر من خلف الكوكيز، ويتبدّل الاسم والرقم. فيه تشغيل تلقائي كل 3.2 ثانية.
2. **من الداخل:** قسم مثبّت، والكوكيز المختارة تطير إليه وتنقلب نصف دورة مع كل خطوة (ظهرها عليه ملصق المخبز والمكوّنات)، ثم «عاصفة» من مكوّناتها.
3. **المتجر:** تهبط الكوكيز على بطاقتها بالضبط، وتميل مع مؤشر الفأرة. زر «+» يطيّر العلبة إلى السلة.
4. **اصنع علبتك:** علبة مشكّلة من 3 نكهات بسعر ثابت.

بعدها آراء العملاء ونموذج الطلب (يجهّز نص الطلب لنسخه وإرساله).

- **بدون أي تثبيت أو بناء.** HTML و CSS و JavaScript فقط. مكتبة Three.js تُحمَّل من cdn.jsdelivr.net.
- **رسومات الكوكيز والمكوّنات مرسومة بالكود** (SVG)، والكوكيز ثلاثية الأبعاد تستخدم نفس الرسومات، فلا يحتاج الموقع إلى أي صور.
- إذا لم يتوفر العرض ثلاثي الأبعاد، تظهر كوكيز مسطّحة وتبقى كل الوظائف تعمل.
- يحترم إعداد «تقليل الحركة»: يتخطّى المقدّمة ويوقف التشغيل التلقائي والحركات.

## الملفات

| الملف | المحتوى |
|------|---------|
| `index.html` | نصوص الصفحة: الأقسام الأربعة، الآراء، نموذج الطلب، السلة |
| `styles.css` | التصميم. الألوان والخطوط متغيرات في أعلى الملف (`:root`) |
| `script.js`  | رسومات الكوكيز، المحرك ثلاثي الأبعاد، القوس، الأقسام، السلة، نموذج الطلب |

## خصّصه لمشروعك

1. **بريدك الإلكتروني:** في `script.js` غيّر `orderEmail` في إعدادات `SHOP` أعلى الملف.
2. **العملة:** في نفس المكان غيّر `currency` (الافتراضي `ر.س`، مثلًا `ر.ع` أو `د.إ` أو `د.ك`).
3. **الأصناف والأسعار:** عدّل قائمة `COOKIES` في `script.js`. لكل صنف اسم وسعر للعلبة ولون الخلفية وقطعة المكوّنات وقائمة المكوّنات. سعر العلبة المشكّلة في `mixPrice`.
4. **اسم المحل والأوقات ومنطقة التوصيل:** عدّل النصوص في `index.html`. ابحث عن «كوكيز البيت» وعن قسم «أيام الخَبز». نصوص قسم «من الداخل» في `STEPS` داخل `script.js`.
5. **آراء العملاء:** الآراء الحالية أمثلة فقط، استبدلها بآراء حقيقية قبل النشر.
